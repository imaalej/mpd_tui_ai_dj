# Recording the demo GIF

The README hero (`docs/demo.gif`) is a short screen capture of the DJ running. It
is not generated by the app — record it once from a live session and drop the file
in at `docs/demo.gif`, then uncomment the `![the DJ in action](docs/demo.gif)` line
near the top of `README.md`.

## What to show (≈15–25 s)

Aim for a loop that reads at a glance:

1. Start with a **seeded session** — let a few tracks play/skip first so the
   **Session** history has a few rows (`✓ ⏭ » ♥`) and the vibe readout is live.
2. Sit on the default **split** view so the console, history, and the rotating
   **vibe space** are all on screen.
3. Let the cloud **auto-rotate** for a few seconds; **right-drag** to orbit once and
   **scroll** to zoom so the motion is obviously interactive.
4. Optionally press **`[B]`** to cycle a frame and **`[T]`** to flip to the full
   cloud and back.

Keep the terminal at a comfortable size (≈120×40) and a dark background.

## Recipe A — ffmpeg screen record (captures album art)

The faithful option: `ffmpeg`'s `x11grab` records real pixels, so the ueberzug
album-art overlay is included (a scripted terminal recorder can't capture it, since
the cover is a separate X11/Wayland surface, not terminal text).

```bash
# 1. Find the window's geometry (x, y, width, height):
xwininfo        # click the terminal; read Absolute X/Y and Width/Height

# 2. Record ~20 s of that region to mp4 (replace X,Y,WxH):
ffmpeg -y -f x11grab -framerate 24 -video_size WxH -i :0.0+X,Y -t 20 /tmp/demo.mp4

# 3. Convert to a looping, size-reasonable gif:
ffmpeg -y -i /tmp/demo.mp4 -vf "fps=18,scale=1000:-1:flags=lanczos" \
  -loop 0 docs/demo.gif
```

If `docs/demo.gif` is large (> ~8 MB), lower `fps`, `scale`, or the duration, or
palette-optimize:

```bash
ffmpeg -y -i /tmp/demo.mp4 -vf "fps=16,scale=900:-1:flags=lanczos,palettegen" /tmp/pal.png
ffmpeg -y -i /tmp/demo.mp4 -i /tmp/pal.png \
  -lavfi "fps=16,scale=900:-1:flags=lanczos[x];[x][1:v]paletteuse" -loop 0 docs/demo.gif
```

## Recipe B — asciinema + agg (crisp text, no album art)

Lighter weight and pixel-crisp, but it records the terminal cell grid only — the
album-art overlay will **not** appear. Good if you want to show the cloud + panels
rather than the cover.

```bash
asciinema rec -c "bash start.sh" /tmp/demo.cast   # play for ~20 s, then exit
agg /tmp/demo.cast docs/demo.gif                  # cargo install --git https://github.com/asciinema/agg
```

## Recipe C — vhs (scripted, reproducible; no album art)

`vhs` (github.com/charmbracelet/vhs) runs a scripted `.tape` in a headless
terminal. Same album-art caveat as B. Sketch:

```tape
# demo.tape
Output docs/demo.gif
Set FontSize 16
Set Width 1200
Set Height 800
Type "bash start.sh"  Enter
Sleep 8s          # let a session seed + the cloud spin
Type "b"  Sleep 2s
Type "t"  Sleep 3s
```

```bash
vhs demo.tape
```

## After recording

1. Confirm `docs/demo.gif` plays and loops.
2. Uncomment the embed in `README.md`:
   ```markdown
   ![the DJ in action](docs/demo.gif)
   ```
3. `git add docs/demo.gif README.md` and commit.
